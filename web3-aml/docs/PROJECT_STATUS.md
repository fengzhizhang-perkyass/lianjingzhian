## 地址风险评分

行为画像 51 维、上下游标准化偏离 102 维、有向结构角色 18 维，共 171 维，交给一个联合 LightGBM。没有重复 GraphSAGE，也没有当前 Gate。
单组模型只提供诊断分；Native TreeSHAP 解释实际综合模型，组贡献与原始 margin 加和核对通过。

| 指标 | 当前测试结果 |
|---|---:|
| AP（项目 PR-AUC 字段） | 0.5429 |
| F1 | 0.5520 |
| Precision | 0.8665 |
| Recall | 0.4050 |
| ROC-AUC | 0.8804 |
| Brier | 0.0298 |
| Top-500 已知测试候选命中 | 488/500（97.6%） |

严格同预算重新训练消融：去行为 AP 0.4799，去邻域偏离 0.2829，去结构 0.5114，去方向 0.3445。
完整模型在本划分优于各移除模型；不把确定性树相同种子输出算作独立重复验证。
完整设计、四轮实验、引用和复现：[RISK_SCORING_REDESIGN.md](RISK_SCORING_REDESIGN.md)。

## 追踪与报告

当前默认深度 4、宽度 5、锚点门槛 30、Top-10、在线关系检查上限 2,000、最多连续 3 个低分连接节点。原 Beam 保留为历史对照。
默认未知高风险示例 `1EVmeeBuxj5jzUitfAjAiSYZwM6A6owyFS`：风险仍为 72.7625，3 条展示路径、7 条唯一边、最深 4 跳；低分连接风险不变，有真实见证。路径仍可共享前段，不是三条独立资金链。
低风险 Seed 也可能发现通往风险锚点的关系，这不改变其地址评分。九个原 Demo ID 不变。
19 组对照/消融、48 个构造图、36 开发/72 评估 Seed：相对旧 Beam 的累计预测锚点 5→23、唯一边 5→59，非空 Seed 4→17；更宽松的搜索有更高锚点覆盖，成本与真值边界完整保留。
PPR 在本样本没有额外覆盖，默认关闭。离线索引成本与温启动搜索分别统计，后续优化复测属于重复评估。
Evidence JSON 包含三类评分证据、联合归因、校准、路径、低分连接见证、搜索边界、稳定路径/证据 ID 和版本。Seed、评分与数据版本错配会拒绝；模板报告与 LLM 失败回退可用。
报告使用固定Evidence快照及事实目录，数字由程序渲染；来源定位支持RFC 6901 Pointer、具体特征行/路径段以及当前案例的154个地址记录和139对原始有向关系。报告可下载完整审计包，故障演示明确标注人为注入与模拟API。哈希为本地一致性核查，不是签名存证。
DeepSeek官方API真实连接和网页报告已验收，显式关闭思考模式。两次真实报告耗时约18.86/20.50秒，均52条声明通过，23/23必选事实齐全；网页连接见证定位和下载审计ZIP核对通过。详见[真实连接记录](DEEPSEEK_CONNECTION.md)。

## 评估边界

测试集已用于此前版本，本轮是重复基准评估，不是独立外部盲测。生命周期汇总输入不能还原历史可见信息。
预算命中率只对已知标签测试地址有效；unknown 真实命中率未知。风险、路径、归因用于辅助分析，不作为法律结论。

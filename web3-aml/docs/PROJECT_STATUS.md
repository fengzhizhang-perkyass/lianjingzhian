# 当前系统功能

更新：2026-10-21。当前主入口为 **宣传首页＋四模块分析工作台**，启动命令 `python run_web.py`，访问 **http://127.0.0.1:8000/**。

| 核心模块 | 已实现能力 | 页面 |
|---|---|---|
| 地址风险评分 | 171 维联合 LightGBM、0–100 风险分、三类诊断、TreeSHAP、全量队列 | 调查优先队列、地址风险分析 |
| 资金关系追踪 | 风险锚点索引、连接见证、预算搜索、覆盖选路、32 跳模式、可拖动关系网络 | 关系链追踪 |
| 可解释报告 | Evidence、带类型事实、声明核验、局部修复、证据导航、审计下载 | AI分析报告 |

全量查询覆盖 822,942 个地址与 2,784,344 条有向关系。九个演示地址及三个 32 跳精选长链案例已准备，当前网页可以串联评分、追踪和报告。

代表性结果为：已知标签测试集 Top-100 命中 100/100，Top-500 命中 488/500；72 个评估起点累计预测锚点 5→23、唯一边 5→59；120 个人为故障全部拦截，模拟局部修复保留 1,200 条正确声明。

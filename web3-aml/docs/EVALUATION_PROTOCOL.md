# 评估与证据边界

## 当前 V2.0 协议

当前使用行为 51 维、上下游偏离 102 维、有向结构 18 维的联合 LightGBM；综合分经过类别加权赔率校正与验证温度校准。三个独立诊断分不参与概率平均，联合 TreeSHAP 解释实际主模型。
按早期开发、晚期开发、最近验证三个时间段的 AP 加权 0.2 / 0.2 / 0.6 选配方与树预算；最近验证段还服务早停、校准和阈值选择，因此有选择偏差。
选择 compact 标准化偏离融合；分类阈值 0.2795，UI 等级边界 30 / 60 / 80，追踪扩展阈值 30。
训练 / 验证图排除触及未来节点的边，测试与部署采用完整图；生命周期特征的静态快照局限仍在。
移除模型使用相同 compact 预算、种子、校准和早停协议重新训练；去方向对照将边无向化后重建偏离与结构。
当前树无随机子采样，不把不同种子的相同输出视作独立证据。历史神经均值与当前单树结果明确区分。
公开测试集此前已被查看，连续开发可能适应该基准，不是外部盲测。Top-K 只计算已知标签测试候选。
详见 [风险评分重构](RISK_SCORING_REDESIGN.md)。**以下 V1.1、调查层、IG 和 Gate 内容为历史协议，当前使用联合 TreeSHAP。**


## 真实数据与试运行

官方 Actors 数据的 CSV 通过 Git LFS 媒体端点下载，下载清单记录 SHA-256 与字节数。
地址特征表含多时间步记录。V1 保留每个地址最新时间步的一条记录，标签映射 `1 → illicit(1)`、`2 → licit(0)`、`3 → unknown(-1)`。

`--max-nodes 40000` 对标签表做确定性分层采样，再取采样地址的诱导子图。unknown 参与采样和推理，但不进入监督损失。
这是**真实数据上的工程试运行**，绝不能把其指标说成全量 Elliptic++ 指标。全量运行不传 `--max-nodes`。

## 时间与数据泄漏

按唯一时间步 70/15/15 划分已知标签节点，地址不会跨集合重复。
缺失值中位数与 scaler 只在训练节点拟合。验证集用于早停、温度校准和分类阈值选择，测试集不用于调参。
V1.1 的 signed log1p 变换、训练集拟合参数、±8 截断和四项绝对区块高度特征置零规则保存在 checkpoint 中；训练、全量推理与 IG 使用同一套变换。
GraphSAGE 训练 / 验证时移除截止时间之后节点的关系边，测试和全量风险预计算使用当前完整图。

**重要局限**：官方地址特征可能包含生命周期汇总，例如首次 / 最后出现区块和生命周期总量。
仅按 timestep 划分不能还原历史时点可见特征，因此当前实验属于静态地址快照风险分析，不能宣传为无未来信息的在线早期检测。
未知标签节点可作为可用邻域特征，禁止把任何真实标签输入模型特征、在线邻域证据或追踪评分。

## 指标

比较四个独立模型：LightGBM、Behavior MLP、GraphSAGE、Dual-View。
PR-AUC 采用 `average_precision_score`（Average Precision）；分类指标采用各模型验证集选择的 F1 阈值。
UI 的 LOW / MEDIUM / HIGH / CRITICAL 阈值固定为 30 / 60 / 80，和评估分类阈值用途不同。
综合分为 `100 × sigmoid(fused_logit / T)`。分支分数未分别校准，不是可直接比较的校准概率。
V1.1 训练使用加权 BCE。导出的三个神经风险头将 bias 减去 `log(N_negative_train / N_positive_train)`，再对综合头在验证集拟合温度。LightGBM 的 balanced 权重也在导出概率时修正赔率并温度校准。
修正针对训练损失的类别权重偏移，不能保证跨时间或 unknown 人群校准有效。加权训练 checkpoint 与修正后 checkpoint 分别保存；概率导出策略在最终测试前确定。
邻居采样设置与随机种子写入产物。它是可复现的采样推理，不宣称精确全邻域推理。

## V1.1 优化与重复评估

输入、损失和融合方案只在原训练区间内的两组时间划分开发（≤22 / 23–28，≤28 / 29–34）。
冻结后，四种神经候选各运行 42、43、44 三个种子，LightGBM 运行一次。每类代表种子按验证 AP 选择，融合代表为 seed 43；禁止根据测试 AP 改选种子。
旧测试集已经被此前版本查看，本轮属于同一基准上的重复评估，不能当作全新独立外部测试。验证集同时服务早停、校准、阈值和种子选择，其成绩存在选择偏差。
三种子的均值和样本标准差、成对 AP 差值、固定 50/50 融合消融及所有种子的 Top-K 都在 [优化报告](../artifacts/experiments/risk_v2/REPORT.md) 保存。固定融合使用匹配的输入、损失、训练预算和种子独立训练。
Top-100 / Top-1% 仅对 56,436 个已知标签测试地址排序计算，不能作为 unknown 的命中率或整体准确率。三个种子的融合平均 AP 未超过 GraphSAGE，不能声称融合全面最优或具有统计显著优势。

## 调查增强版

新增拓扑树输入八项无标签有向图统计。训练 / 验证图按各自截止时间过滤未来节点的边，原静态快照局限仍存在。
GraphSAGE、Dual-View、拓扑树的固定组合权重只在原训练区间两个开发折上选择，最终使用验证集选代表种子 43、温度和分类阈值；不按测试 AP 改选种子。
三个最终组合改变神经专家种子，树未启用随机子采样而输出相同，不能把它描述为三个独立树模型重复实验。
专家告警用各自验证集阈值，共识 / 分歧状态不输入标签。“一致未告警”不证明正常，分数极差不是错误概率或置信区间。
调查优先级单独用于排序，原双线路风险仍指导关系追踪。TreeSHAP 只解释树专家原始输出；原生贡献之和与树 raw margin 的一致性已验收。
完整对照和全部种子的预算结果保存在 [调查实验报告](../artifacts/experiments/investigation_v1/REPORT.md)。

## 地址解释

IG 解释行为分支 logit，基线是标准化后的零向量（训练均值）。按绝对归因大小选 Top-5，同时保留正负号。
GraphSAGE 分支也使用节点特征，因此“图分支”不等同于纯结构模型。
Gate 是 embedding 融合系数，不能视为行为 / 图信息对最终分数的因果贡献比例。
一跳邻居为入 / 出邻居的去重并集，排除自身；二跳证据按固定种子采样。

## 追踪

原始边方向保留，只沿 outgoing 扩展。搜索分由节点风险、邻域风险、度数惩罚构成，再对路径长度衰减。
`visited_nodes` 是保留路径节点的唯一地址数（含 Seed）。
`candidate_nodes` 是查看过的候选唯一地址数（不含 Seed），`pruned_nodes` 是候选中未保留的唯一地址数。
`pruned_expansions` 单独计数剪枝事件，避免把重复地址和扩展次数混同。
Top-K 可以包含同一条长路径的前缀，这是文档伪代码逐层收集 Beam 的结果。
路径表示交易关系，不证明严格时间连续的资金流、实际转移金额或犯罪行为。

## LLM

LLM 只能编写六部分叙述，所有数值 / 地址通过 JSON 字段引用写入，程序负责校验和替换。
非法引用、未引用数字、部分明确犯罪断言、超时及不兼容 API 都触发模板回退。
此校验不是对全部自然语言事实的形式化证明；仍须人工复核。完整 Evidence JSON 可下载，系统标准局限会强制附在报告的第六部分。

接口依据 [OpenAI Chat Completions 官方参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create/)。
项目使用该接口以适配用户配置的 OpenAI-compatible 服务，不自动读取 Codex 的密钥或替用户指定模型。
